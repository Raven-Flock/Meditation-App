# Fonts

Figtree and Fraunces, SIL Open Font License 1.1. Licenses: [OFL-Figtree.txt](./OFL-Figtree.txt), [OFL-Fraunces.txt](./OFL-Fraunces.txt).

- `figtree-latin-var.woff2`: Figtree (Erik Kennedy), from google/fonts `ofl/figtree/Figtree[wght].ttf`. Instanced to wght 400–600, latin subset.
- `fraunces-latin-var.woff2` and `fraunces-latin-var-italic.woff2`: Fraunces (Undercase Type), from google/fonts `ofl/fraunces`. Instanced to wght 300–400 (roman) and 400 (italic), with SOFT 0 and WONK 0 and the full opsz range. Latin subset.

The subsets were made with fontTools (`instancer` + `pyftsubset`, layout features kern, liga, calt, onum, pnum and tnum). They are modified versions under OFL 1.1, and the Reserved Font Names are not used for the files.
